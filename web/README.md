# Академия Чудес — сайт-концепт

Выездные шоу и аниматоры в Братске. Реализация арт-дирекции `product-theater` (см. `../design-concept.md`).

## Запуск

```bash
cd web
npm install
npm run dev
```

Сборка: `npm run build` → папка `dist/`.

## Что уже есть

- Hero + афиша из 4 актов
- Полный каталог программ из VK Market
- Райдер формата (50 мин / 2 аниматора + диджей)
- Заявка → копирует текст и открывает VK
- Контакты и рейтинги из открытых источников
